# Data

Put the travel time grid here:

```
data/helsinki_region_travel_times_to_railway_station/helsinki_region_travel_times_to_railway_station.gpkg
```

It is the same file as in the AutoGIS course (lesson 4) and comes from the Helsinki Region Travel Time
Matrix by the Digital Geography Lab, University of Helsinki (CC BY 4.0).

The metro and train layers and the weather are downloaded automatically when the notebook runs.
